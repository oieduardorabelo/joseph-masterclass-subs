# Joseph's Communication Masterclass - Subtitles

Video player with English and Japanese subtitles for Joseph's Communication Masterclass.

**[Watch here](https://oieduardorabelo.github.io/joseph-masterclass-subs/)**

## Subtitles

- `en.srt` — English (transcribed with [whisper.cpp](https://github.com/ggml-org/whisper.cpp))
- `ja.srt` — Japanese (translated with Claude Haiku)

Use the CC button (⋮ menu) in the video player to switch between English and Japanese.
